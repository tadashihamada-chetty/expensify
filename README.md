# Expense Tracker

A simple web-based expense tracker built with HTML, CSS, and JavaScript.

## Project Status

🚧 **In Development**

The core functionality of the application is currently working. Additional features and improvements will be added as development continues.

## Current Features

- Add expenses
- Select expense categories
- Record expense amounts
- Display transaction history
- Calculate total spending by category
- Calculate and display the current balance
- Store data using Local Storage
- Generate unique IDs for transactions

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage API

## Planned Features

- Delete expenses
- Filter expenses by category
- Add expense name and date selection
- Improve balance validation
- Improve responsive design
- Improve overall UI/UX
- Final testing and bug fixes
